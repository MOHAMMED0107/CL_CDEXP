== Use the phone over Wi-Fi (no cable) ==
This lets every option in this menu reach your phone over Wi-Fi, so you can unplug the cable.
Your phone's Wi-Fi address: 192.168.1.42

Please read before you say yes:
  - Only do this on Wi-Fi you trust, like your home Wi-Fi. Not on cafe, hotel, airport,
    school or other public Wi-Fi.
  - While it is on, the phone accepts debugging connections over this Wi-Fi. Only computers
    you already allowed get in. This computer is recognised by its "adb key" (a small
    secret file adb keeps here, remembered when you tapped Allow). Any other computer makes
    the phone ask "Allow USB debugging?" - tap Cancel if you did not start it yourself.
  - This classic Wi-Fi link is not encrypted: one more reason to use only trusted Wi-Fi.
  - Nothing is installed and none of your settings or data change. Calls, SMS, notifications
    and banking apps are not affected. It switches off when the phone restarts, or when you
    choose this option again and go back to USB.
  - This computer must be on the same Wi-Fi (or the same home network) as the phone.
OK, nothing was changed.
