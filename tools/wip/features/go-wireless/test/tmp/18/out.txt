== Use the phone over Wi-Fi (no cable) ==
This lets every option in this menu reach your phone over Wi-Fi, so you can unplug the cable.
Your phone's Wi-Fi address: 192.168.1.42

Please read before you say yes:
  - Only do this on Wi-Fi you trust, like your home Wi-Fi. Not on cafe, hotel, airport,
    school or other public Wi-Fi.
  - While it is on, the phone accepts debugging connections over this Wi-Fi. Only computers
    you already allowed get in. This computer is recognised by its "adb key" (a small
    secret file adb keeps here, remembered when you tapped Allow). Any other computer makes
    the phone ask "Allow USB debugging?" - tap Cancel if you did not start it yourself.
  - This classic Wi-Fi link is not encrypted: one more reason to use only trusted Wi-Fi.
  - Nothing is installed and none of your settings or data change. Calls, SMS, notifications
    and banking apps are not affected. It switches off when the phone restarts, or when you
    choose this option again and go back to USB.
  - This computer must be on the same Wi-Fi (or the same home network) as the phone.
Switching the phone to Wi-Fi mode (its debugging service restarts, a few seconds)...
Connecting to 192.168.1.42:5555 ...
Could not connect over Wi-Fi. adb said: failed to connect to '192.168.1.42:5555': Connection refused
Common reasons:
  - This computer is on a different network (another router, mobile hotspot, or a VPN is on).
  - Guest Wi-Fi or "AP isolation" stops devices on the same Wi-Fi from seeing each other.
  - A firewall on this computer blocks adb.
  - Some MIUI versions block this classic Wi-Fi mode.
The phone is still listening for Wi-Fi connections until it restarts.
Left as is. Restarting the phone switches it back to USB-only mode.

Android 11 and newer (yours too) have their own Wi-Fi connection, called "Wireless debugging".
It is encrypted, but needs a few taps on the phone:
  1. Make sure the phone and this computer are on the same Wi-Fi.
  2. On the phone open Settings > Additional settings > Developer options.
  3. Turn on "Wireless debugging". If it asks "Allow wireless debugging on this network?",
     tap Allow (only on your own Wi-Fi).
  4. Tap the words "Wireless debugging" (not the switch) to open its page.
  5. Tap "Pair device with pairing code". A box shows a 6-digit "Wi-Fi pairing code"
     and an "IP address & Port", for example 192.168.1.42:37123.
  6. Keep that box open and type both here when asked.
  7. Then look at the Wireless debugging page again. Its "IP address & Port" has a
     DIFFERENT port number (for example 192.168.1.42:41567). Type that when asked.
  (By hand it is: adb pair IP:PORT CODE, then adb connect IP:PORT)
  Wireless debugging switches itself off when the phone leaves this Wi-Fi or restarts.
OK. To try it later, choose this option again.
